# iOS SDK implementation (data attributes)

> **Publisher integration:** use the full, up-to-date guide: **[Doceree_iOS_SDK_Integration_Guide.md](./Doceree_iOS_SDK_Integration_Guide.md)** (SDK **6.3.2**).

This file retains **copy-paste examples** for consent, login, and data attributes only.

- CocoaPods: `import DocereeAdSdk` (not `DocereeAdsSdk`).
- Hashed fields: **64-char lowercase SHA-256 hex**, **no** `sha256:` prefix (SDK does not hash).

See the integration guide for AppDelegate setup, **integration checklist**, **ATT / Info.plist**, **identity lifecycle**, **Platform Guide** cross-reference, ad load errors, ad slots, and ad sizes.
